# App Hotel

Aplicativo mobile desenvolvido em .NET MAUI (C# + XAML) para a disciplina de Programação Mobile I, a partir da Agenda 13 – Centro Paula Souza

O app simula a contratação de uma hospedagem e demonstra o uso de componentes de interface e de **BindingContext**.

## Estrutura do repositório

```
app-hotel-maui/
├── MauiAppHotel/       # projeto .NET MAUI
│   ├── Models/         # Quarto, Hospedagem, InfoApp
│   ├── Views/          # Contratacao, HospedagemContratada, Sobre
│   ├── Platforms/      # Android e Windows
│   └── Resources/      # ícone, splash e imagens SVG
├── sobre.png, tela.png # capturas de tela
└── README.md
```
